#001

Celeste RL

Teaching a reinforcement learning agent to play Celeste through the game’s real controls.

I built a Python environment, with a small C# plugin, that runs the game at about 2,600 frames per second. Then I used it to study PPO, learning from demonstrations, and how well a policy copes with game states it never trained from.

Without demonstrations, PPO never cleared the first room. With seven demonstrations found by a search, training from varied starts beat a fixed start on held-out states. The same design didn’t replicate in Room 2, and the write-up says so.

#002

WCA Analysis

A model with r² ≈ 0.95 was still wrong by years.

An analysis of the complete World Cube Association results export, every official speedcubing competition and competitor on record, testing claims that look obvious until you check them.

  • An exponential trend fit the 3x3 world record with r² ≈ 0.95, yet every version of it called the sub-3-second record 2.5 to 4+ years too early.
  • A simple home-versus-away comparison is confounded, because people who travel to compete are more dedicated. Comparing about 13,900 competitors against themselves, they do better away from home (p = 1.3e-67).
  • Found two bugs in loading the raw export, duplicate competitor rows and mixed-type event IDs, and pinned both with tests that run in CI.

#003

DualSense Quick Menu

A PS5-style control centre for Windows.

Press the PS button on a DualSense mid-game and an overlay opens for Spotify, volume, switching apps and power, without putting the controller down. In closed alpha with testers.

  • Input latency. In CPU-heavy games, presses waited 50–100 ms for CPU time. Raising the controller threads above the game’s priority fixed it.
  • Windows. A controller-driven Alt-Tab built from the live window list, a global shortcut, and a tray app that can start with Windows.
  • Spotify. Browsing and playback on a worker thread, so the overlay never waits on the network.
  • Shipping. Every build runs the tests, packages with PyInstaller, then self-tests the finished exe before it’s zipped.
